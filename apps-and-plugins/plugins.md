# 🔌 Plugins

Unlike containers, plugins are installed directly into Unraid. Which can potentially be problematic, causing problems after a major Unraid update. Also having too much plugins for the Web UI can slow it down. You can find plugins on the Community Apps.&#x20;

Unraid is updating rapidly so a lot of the cool plugins are being baked into Unraid itself. Here are some plugins you can take a look at. Quite a few of these will be mentioned in the App Installation guides.&#x20;
